Privacy Policy

Home Dashboard · Last updated November 16, 2026

Home Dashboard is a personal, single-household project that shows temperature and humidity readings at home.esemay.com. It is not a commercial product and has no other users. Only the site owner's own accounts are connected.

What data it accesses

  • SensorPush: sensor names, temperature, humidity, dew point, barometric pressure, battery level, signal strength, and gateway status.
  • Google Nest (via the Smart Device Management API): the thermostat's temperature and humidity readings, setpoints, mode, and heating/cooling status. Access is read-only. The dashboard never changes thermostat settings.

No names, email addresses, locations, contacts, or other Google account data are requested.

How the data is used and stored

An automated job runs about every 15 minutes, reads the data above, and saves it as a file in the site's GitHub repository. The dashboard displays that file. Roughly the most recent 24 hours are kept, and each update replaces the previous file.

The readings are public. Anyone who visits the dashboard or its repository can see them. Account credentials and access tokens are stored as encrypted GitHub Actions secrets and are never published.

Sharing

The data is not sold, shared with third parties, used for advertising, or used to train any AI or machine-learning models. Beyond being displayed publicly on the dashboard, it is not used for any other purpose.

Google API Services User Data Policy

Home Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access to Nest data can be removed at any time from the Google account's third-party connections page or the Nest partner connections settings. Once access is revoked, no new Nest data is collected, and the stored readings age out within about 24 hours.

Contact

Questions about this policy can be raised through the site's GitHub repository.
